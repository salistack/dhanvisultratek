# Dhanvis Ultratek Website

Website for Dhanvis Ultratek - Non-Destructive Testing Services

## Deployment

This website automatically deploys to cPanel hosting when you push to:
- `main` branch
- `salistack` branch

### Required GitHub Secrets:
- `FTP_USERNAME`: umairsalih2001@dhanvisultratek.com
- `FTP_PASSWORD`: your cPanel FTP password

### Manual Deployment:
If automatic deployment fails, you can trigger the alternative deployment workflow manually from the GitHub Actions tab.

## Website Structure:
- `index.php` - Homepage
- `about.php` - About page
- `services.php` - Services page
- `contact.php` - Contact page
- `css/` - Stylesheets
- `js/` - JavaScript files
- `img/` - Images
- `includes/` - PHP includes
